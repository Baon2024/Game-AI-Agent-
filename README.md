# Game-AI-Agent #



An AI Agent-powered Tic-Tac-Toe game. The Agent is able to see the human's moves, and respond, via websocket connection.

The Demo was recorded using a Cerebras-hosted LLM for inference speed (how fast the response is), but locally-run models
via Ollama hosted on your own laptop also work - just a slower waiting time for each move.
